# proyecto-RepartosYA
Plataforma Web + Aplicación Móvil  para la gestión integral de pedidos, trazabilidad con comprobantes fotográficos y control de rutas entre comercios.

## Caracteristicas Principales
- **Panel Web de Administración:** Control Total para la Administración y Gestión de Accesos.
- **Aplicación Móvil para Repartidores:** Registro de pedidos pendientes con sección individual en el cierre mediante un indicador de comprobante y medio de pago.
- **Sección Pública (de sólo lectura):** Vista de información actualizada para usuarios externos.

## Tecnologias Utilizadas
- **Frontend:** React, JavaScript, (añadir más en caso de uso).
- **Backend:* Node.js, Javascript.
- **Repositorio:** Github.
